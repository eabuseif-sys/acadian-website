# Acadian International Trade website

Static website (HTML / CSS / JavaScript, no build step). English + Arabic (RTL).

## Structure
- `index.html` : the page
- `css/style.css` : styles (light/dark theme, responsive)
- `js/main.js` : language toggle, mobile menu, image lightbox, contact form
- `assets/img/` : all photos and the company logo

## Publish on GitHub Pages
1. Create a repository and upload all files, keeping the folder structure (`index.html` must be at the repository root).
2. Repository **Settings > Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then **Save**.
4. After a minute the site is live at `https://<username>.github.io/<repository>/`.
